# DL5_UNIT_006：激光模式 DAX 三项异常定位

## 目标

用一次诊断 bitstream 和 ILA 上板抓取，定位激光模式下的三个实测现象：

1. 配置每行 16 点，但示波器仅见约 8 个 DAX 台阶；
2. 配置线首恢复 5 us，但实测约 15 us；
3. 线尾回扫后存在一个上升尖峰。

## 已知测试条件

- 16 x 16，`dac_sample=4`，外部激光周期约 2 us；
- X 范围 `0x1999..0xE665`，线首恢复 `0x0006[15:0]=5` us；
- X 回扫 `0x000F=1` us，扫描延时 `0x0206=100`（800 ns）；
- 当前 ILA 已证明：每个被 State14 接收的脉冲均完整执行 State15 的 100 个 eth_clk 计数。

## 边界

- 本单元只增加 ILA 调试连线并把 `ila_1`、`ila_2` 深度由 1024/2048 提升至 4096；不改变扫描、FIFO、寄存器或 IO 的功能行为。
- 不修改 XDC、BD 或业务 IP；`ila_1.xci`、`ila_2.xci` 的调试深度修改由用户“用 ILA 抓并一次加全探针”的授权覆盖。
- 板卡下载仍由用户执行；AI 负责产出 bitstream、LTX 和受控 ILA 抓取脚本。

## 判定标准

- 完整行：记录所有激光上升沿、被接收的行首事件、`dacx_tk_point_cnt`、State16 写入和 FIFO 反压，确定丢失发生在输入/状态门控/写侧/读侧的哪一级。
- 行首：记录 State2 计数与 DAC 读侧实际输出，确认恢复时间是否由 FIFO word 数保证。
- 线尾：以 FIFO bit33 的行尾标记为触发，捕获最后像素、回扫、FIFO 空/读使能和下行起始锚点，量化尖峰前后的 DAC 码值。
