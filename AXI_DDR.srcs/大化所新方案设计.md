# 大化所新方案设计

背景：

大化所客户需求：将飞秒激光器作为跨时域四维电镜的统一激发光源，飞秒激光器发送脉冲信号给采集卡，进而控制SEM的束闸偏转和信号采集

一、系统架构

二、拍照流程

（1）上位机设置必要的采集参数，各个延时时间，选择合适的驻点时间，点击下发参数，上位机反馈参数是否设置合理。

（2）正确设置参数后，开启飞秒激光器

（3）点击扫描图像

四、各个时间参数配置情况如下表1所示：

| 参数 | 描述 | 配置情况 | 取值范围 | 最小步进 | 备注 |
| --- | --- | --- | --- | --- | --- |
| dwell time | 像素驻点时间 | 通过上位机软件设置 | tDWELL>=2us |  | 与激光同步信号频率相关，dwell time <= 500KHz |
| dwell switching time | 点切换时间 | 无需配置 | dwell switching time <= line time + fall time |  | 切换时间小于行等待+下降沿时间+帧等待时间 |
| blanker delay time | 束闸延时间 | 通过上位机软件设置 |  | 5ns | blanker delay time+blanker time <= 激光频率 |
| blanker time | 束闸保持时间 | 通过上位机软件设置 |  | 5ns |
| acq data delay time | 采集延时时间 | 通过上位机软件设置 |  | 20ns | acq data delay time+acq time <= 激光频率 |
| acq time | 像素采集时间 | 通过上位机软件设置 |  | 20ns |
| Line change time | 行切换时间 | 无需配置 |  |  | 行扫切换结束后，接收到触发信号开始采集 |

五、输入输出信号

| 输入/输出 | 名称 | 触发/电平 |
| --- | --- | --- |
| input | Laser Sync Signal Input | 高电平触发，2.5V TTL |
| output | Blanker Output | 可选高低电平触发，3.3VTTL |

六、待讨论

1、blanker束闸的最小步进为5ns，驻点时间延时、采集数据延时最小为20ns

2、激光输出的同步信号接口是SMA

3、需要将探测器模块邮寄合肥进行改装，来回时间大概为5-6天（主要是快递时间）

4、原来ns激光器和blanker 联用功能是否继续保存

5、方案确认后，完成验证时间1~2周
